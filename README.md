# Super30 Python Final Loop and Function Project

## Project Objective

The objective of this project is to combine Python concepts learned through
loops, while loops and functions and apply them to practical mini-programs.

The project demonstrates reusable functions, condition-controlled loops,
iteration, lists, dictionaries, input validation, error handling and
menu-driven applications.
